# Dashboard opérationnel

Le Dashboard HospiCore donne une vue immédiate sur l’activité de l’hôtel.

## Fonctionnalités livrées

- indicateurs d’occupation, arrivées, départs et tickets ;
- briefing opérationnel ;
- alertes prioritaires ;
- main courante filtrable ;
- création rapide d’une transmission ;
- planning synthétique de la journée ;
- groupes attendus ;
- navigation responsive sur ordinateur, tablette et mobile.

## Données

Les données sont actuellement des données de démonstration. Elles seront remplacées par les données de l’API NestJS lors du module d’intégration.
